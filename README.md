# Car Detailing Demos — Apex Auto Detail

Three-tier demo website set for a fictional luxury car detailing brand, **Apex Auto Detail**. Built as self-contained, deploy-ready static pages for GitHub Pages.

## Live structure

```
/                  → demo selector (root index.html)
/starter/          → Starter tier ($749)
/standard/         → Standard tier ($1,249)
/premium/          → Premium tier ($2,499)
```

## Tiers

| Tier | Highlights |
|------|------------|
| **Starter** | Animated car silhouette with gloss/shine keyframes, 3 service cards, contact info, IntersectionObserver fade-ins. |
| **Standard** | Light-streak hero on load, scroll-triggered shine-wipe dividers, 5 services, testimonials, before/after teaser, contact form, map placeholder, hamburger nav. |
| **Premium** | Cinematic particle hero with sweeping light beam, 7 flip cards, CSS-only drag before/after slider, pricing table, quote form with checklist, testimonial carousel, sticky transparent→charcoal nav, SEO meta + LocalBusiness schema. |

## Theme

- **Colors:** deep charcoal `#1A1A2E`, metallic silver `#C0C0C0`, rich black `#0D0D0D`, accent red `#C0392B`, cream white `#F8F6F2`
- **Fonts:** Bebas Neue (headings), Raleway (body) — via Google Fonts CDN
- **Aesthetic:** dark, high-end garage meets luxury showroom; metallic shimmer, red accents used sparingly
- Fully mobile responsive

## Deploy (GitHub Pages)

Enable Pages on the repo (source: branch root). Base path: `/Car-Detailing-Demos/`.

Each HTML file is self-contained with no dependencies beyond the Google Fonts CDN.
